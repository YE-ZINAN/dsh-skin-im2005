# IM2005 — 2005 年代即时通讯风格皮肤 · DeepSeek Harness

把 **DeepSeek Harness 桌面端**换成 2005 年即时通讯软件的样子：直角窗口、1px 硬边框、宋体、蓝色渐变标题栏、好友分组式侧栏，还有一条"形象秀"右侧列。

> **这是一个非官方的第三方皮肤插件。** 与任何即时通讯厂商（包括腾讯 / QQ）**无关联、未获授权、未获赞助**。
> 插件内**不含任何第三方图片、图标、商标或字体资源** —— 全部美术为原创 SVG（详见 [NOTICE.md](NOTICE.md)）。

## 功能

| 功能 | 说明 |
|---|---|
| **余额** | 走一方账户接口查余额，不自己碰凭证；再点一次关闭弹窗 |
| **形象秀** | 右侧三段可折叠面板（好友形象 / 个人空间 / 我的形象），可固定 |
| **跨会话备注框** | 一块**所有会话共享**的草稿纸：在 A 会话里记下"切到 B 会话要做什么"，切过去那行字还在。每次输入即保存，可拖动、可最小化，带复制/清空 |
| **美式八球** | 跟电脑打（也可切双人）：每杆停稳自动存档，关掉再开接着打；可拖边缘缩放 |
| **扫雷 20×20** | 左键翻开 · 右键插旗 · **单击数字即可连开**；首点必安全；简单 50 / 普通 80 / 困难 120 颗雷 |
| **Token农场** | 一株植物，**生长无上限**（7 档视觉 + 无限递进）。每完成一轮 AI 回复 +1 滴水，余额每降 ¥0.10 +1 滴，纯时间也会缓慢生长；**没有收菜、进度不会倒退** |
| **德州扑克** | 6 人桌（你 + 5 个电脑，五种打法原型）。核心是**牌型辅助**：右侧常驻九档天梯（当前牌型高亮，另带「打平时怎么比」一列）、实时显示你现在是什么牌、摊牌时说清为什么输赢；筹码独立，输光自动重买，每步自动存档 |
| **后台任务** | 点开才看：列出正在跑的会话（用时 / 子代理 / 工具调用 / 计划任务）。平时不显示任何标记，跑完也不会响 |
| **专注模式** | 点开输入专注几分钟（1–180，默认 25）：这段时间内**插件一声都不响**（八球 / 扫雷 / 农场的音效全部静音），时间到**自动恢复**。思路来自 [dsh-quiet](https://github.com/YE-ZINAN/dsh-quiet)（那边管任务栏闪烁，这边管界面内静音，各自独立计时） |

## 安装

### 前置
- 已安装 **DeepSeek Harness 桌面端**
- Node.js（如果要用命令行安装方式）

### 方式 A：命令行安装（推荐）

```powershell
# 1) 把本仓库放到一个固定位置（link 安装后不能删）
#    例如 D:\plugins\dsh-skin-im2005

# 2) 指向它安装（把 <DSH安装目录> 换成你自己的）
$env:DSH_HOME = "$env:USERPROFILE\.dsh"
& '<DSH安装目录>\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop `
    add 'link:D:\plugins\dsh-skin-im2005'

# 3) 完全退出并重启客户端
```

### 方式 B：手工放置

1. 把整个文件夹放到 `<DSH_HOME>\profiles\desktop\node_modules\dsh-skin-im2005`
2. 编辑 `<DSH_HOME>\profiles\desktop\package.json`，在 `dsh.profile.bundles` 里加上 `"dsh-skin-im2005"`
3. 完全退出并重启客户端

> ⚠️ **注意**：命令行安装方式会**重算** `dsh.profile.bundles`，有可能挤掉你已装的其它插件条目。
> 装完请检查那个 `package.json`，必要时手工补回。

### 卸载

```powershell
& '<DSH安装目录>\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop remove dsh-skin-im2005
```

|---|---|

## 自定义美术

插件**只带原创 SVG 兜底**，默认没有任何照片。想换成自己的图：

```powershell
# 1) 准备三张图，放进 assets/，按这个命名：
#    my-show.jpg  形象秀立绘（人像/角色图）
#    mascot.png   小图标（方形、建议带透明通道）
#    avatar.png   头像（方形）
# 2) 内联进 client.js
node tools/embed-asset.mjs
# 3) 刷新客户端
```

**删掉 `assets/` 里任意一张图也不会坏** —— 对应位置会自动回退到内置原创 SVG，界面不会缺图。

> 请只放入**你有权使用**的图片。把别人的美术资源打包分发可能侵权，与本项目无关。

## 开发

```powershell
# 语法检查
node --check client.js

# 回归测试（40+ 断言：复刻宿主真实的 token 校验规则、渲染全部组件、点击所有控件）

```

### 项目结构

```
package.json          # dsh.bundle.patch + dsh.client{platform,immediately,inject}
cordis.patch.yml      # 只 insert 一行：挂载本包
index.js              # Host 半区（空实现，只为满足 bundle 契约）
client.js             # 全部视觉逻辑：主题 token + 8 条 slot 注册 + chrome CSS
locale/{zh,en}.json   # 插件卡片文案
icon.svg              # 原创图标
tools/embed-asset.mjs # 把 assets/ 里的图内联进 client.js（可选，见"自定义美术"）
tools/self-test.mjs   # 离线回归测试，不需要启动客户端
```

### 实现要点（想改代码的话）

插件只做三件事，**不读写其它插件的 DOM、不注册全局**：

1. **主题层** —— `ctx.theme.overrideTokens()` 覆盖约 42 个设计 token（圆角 / 描边 / 阴影 / 字体 / 颜色），按 `{light, dark}` 成对给。
2. **装饰层** —— 往宿主声明的 `list` 槽里注册自己的 React 组件（每一条都套了错误边界，插件渲染出错不会拖垮宿主）。
3. **chrome CSS** —— 一小段注入的 `<style>`，用**语义属性**（`[data-windows-titlebar]`、`[data-chat-flow-kind]`、`[data-clock]`、`[data-row-key]` …）和 CSS-module 局部名后缀给宿主已有元素上色。选择器匹配不上时是**无害空操作**，不可能让宿主编译或运行失败。

## 更新日志

### v1.16.1

**修：德州扑克拿到顺子时牌桌会消失**

- 症状：玩着玩着牌桌自己没了（只剩一个小红 `⚠`），重开也一样。
- 根因：评估器"顺子"那一支把「参与比大小的 5 张牌」写成了内部对象 `{high, ranks}`，
  界面给这 5 张牌描金边时调 `.indexOf()` 抛错。牌型判定、牌型名、摊牌解释其实全对，
  只有金边高亮这一步炸掉 —— 但抛在**渲染期**，被错误边界隔离，代价是整张牌桌消失。
  **自己拿到顺子时才触发**（四个人打，十几局就会遇到一次）。
- 修法：那一支传真正的 5 张牌数组；金边高亮加数组类型防御（画不出金边可以忍，把窗口搞没不行）。
- 顺带：渲染之外的引擎调用全部兜底并把错误写真到可查处；错误边界也会留错误原文；
  新增"耐久测试"——200 局、**每个动作之后都渲染一次真实界面**，这次就是它抓到的
  （单元断言与牌型穷举都发现不了：那个错误只在"我拿到顺子"这种具体牌面下出现）。

### v1.16.0

**新增：德州扑克（6 人桌）**

- 工具条上的 `德州扑克` 按钮。你 + 5 个电脑，翻牌前 / 翻牌 / 转牌 / 河牌四轮，
  动作只有 **过牌 / 跟注 / 下注-加注（固定档位）/ 弃牌**；筹码**独立**于工具栏「余额」，输光自动重买。
- **核心是牌型辅助**（这是做它的原因）：
  - 右侧**常驻九档天梯**（高 → 低），**当前牌型高亮**；每档还带一列「**打平时怎么比**」
    —— 七张牌口径下一对 + 两对 + 高牌占 84.7% 的牌局，新手真正输钱的地方是踢脚，不是九档顺序。
  - 实时读数 `你：两对（K 和 7）`：由 **7 选 5 的最优组合**算出，并**把参与比大小的那 5 张描上金边**。
  - 摊牌时给一句人话解释：`两家都是同花，从大到小逐张比：菲菲 的 K 比 Q 大`。
  - 还差什么：同花听牌 / 两头顺 / 卡顺。**不显示任何没前提的胜率数字**。
- 天梯是 **9 档不是 10 档**：皇家同花顺 = A 高同花顺，只作第一档的标注 —— 避免"两个皇家谁大"的伪问题，
  公共牌成皇家时也能正确判平局。
- 电脑有五种打法（紧凶 / 跟注站 / 岩石 / 松凶 / 疯子，悬停可见），诈唬频率**刻意低于 GTO** 但**不为 0**；
  胜率函数**只吃自己的底牌 + 公共牌**，物理上看不到别人的牌。
- 每步自动存档，关掉再开接着打；音效同样受「专注模式」管辖。

**修**

- 工具条按钮顺序：`德州扑克` 与另外三个游戏挨着（排在 `后台任务` 左边，`专注模式` 仍是最后一个）。

### v1.15.0

**新增**
- 专注模式：工具条最右边的 `专注模式` 按钮，输入专注几分钟（1–180，默认 25），这段时间内**插件一声都不响** ——
  八球 / 扫雷 / 农场的音效全部静音，时间到**自动恢复**，也可以提前结束。面板关掉不影响计时；
  存档存的是绝对结束时间，刷新界面、重开客户端都还算数。

  **这个功能的思路来自同作者的 [dsh-quiet](https://github.com/YE-ZINAN/dsh-quiet)**，两边管的是**不同通道**：
  dsh-quiet 走宿主事件接缝做「窗口不在前台时闪任务栏」，本插件的专注模式走界面内静音。
  它们**各自独立计时、互不感知**，可以同时用 —— 从这边开专注不会让 dsh-quiet 一起进入专注，反之亦然。

  **静音不改任何开关**：判定写的是「现在是否还在专注时段」，所以在专注期间你不会发现
  「游戏音效开关被偷偷关掉了」——专注结束后一切照旧。三个游戏各自的音效开关仍然各管各的。

### v1.14.1

**修复**
- 美式八球：**打进自己那一组的最后一颗球会被误判成犯规**。"该打 8 号了吗"原来按**击球之后**的台面算，
  而这一杆正好把自己最后一颗打进，于是被回灌成"你该打 8 号、却先碰到了别的球" = 犯规，回合白送对手。
  用户那边看到的是"我明明打进最后一颗，怎么突然轮到电脑了"。
  现在按**出杆前**的局面判定：打进最后一颗 → 继续出杆，下一杆才轮到打 8 号。
- 美式八球：轮到电脑时提示行无条件写"电脑在想…"，把刚打完那一杆的判定（犯规原因 / 换人）全挡住了，
  出错时没有任何线索。现在优先显示判定结果。
